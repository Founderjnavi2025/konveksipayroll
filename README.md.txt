# KONVEKSI HUD — Multi-Room

Platform pencatatan obras untuk banyak konveksi. Tiap konveksi punya "room" sendiri
dengan data terpisah: pekerja, pekerjaan, tarif, buku gaji, riwayat.

## 🚀 Coba cepat (mode demo, tanpa setup)

1. Simpan 3 file ini dalam satu folder: `index.html`, `style.css`, `app.js`, `supabase.js`
2. Buka `index.html` langsung di browser (double-click) — **atau** serve dengan:
   ```bash
   npx serve .
